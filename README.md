## 🚀 Projects

| Project | What I did | Tools |
|---|---|---|
| **[EV Battery Health Predictor](https://github.com/vrshy/EV-Battery-Health)** · [Live app](https://ev-battery-health-rxtyr4kezt79ceafe8jdw6.streamlit.app/) | Predicted a battery's capacity, State of Health and Remaining Useful Life from one discharge cycle of NASA data (4 batteries, 636 cycles). Explained the model with SHAP and deployed it as a Streamlit app. | Python, XGBoost, SHAP, Streamlit |

Built a 3-page interactive dashboard. | Python, Pandas, Power BI, DAX |
